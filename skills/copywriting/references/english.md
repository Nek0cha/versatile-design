# 英語のキャッチコピー

手順4で、英語の案を作る場合に読む。

## 1. 使う場面

- 技術系、クリエイター系、海外の利用者も想定するサイトで使う。
- 5案のうち1〜2案を英語にする。残りは日本語にする。
- `user-preferences.md` の「英語の使い方」に指定があれば、そちらに従う。

## 2. 長さ

3〜5語を目安にする（`taste.md` の調整欄）。

## 3. 使わないもの

- 空っぽの語：Unlock、Elevate、Empower、Seamless、Supercharge、Revolutionize、Transform、Effortless、Next level、Journey（`anti-patterns.md` の A1）
- 定型の型：「Not just X. Y.」「Where X meets Y」「X, reimagined」（`anti-patterns.md` の A6）
- 感嘆符と疑問形の呼びかけ

## 4. 優先する技

- **意味の二重化**：業界用語と一般の意味が重なる語を探す。開発者向けなら commit、ship、branch、merge、build、craft 向けなら block、cut、frame など。
- **文法の崩し**：副詞の位置に形容詞を置く、自動詞を他動詞のように使うなど、1か所だけずらす。
- 日本語の案と同じく、静かに言い切る。末尾はピリオドで閉じる。

## 5. 日本語のサブコピー

- 英語のキャッチの下に、日本語のサブコピーを1文添えてよい。
- サブコピーは英語の直訳にしない。英語が言っていない事実を1つ足す。
