# 自己批評

手順5で、lint の違反がゼロになった後に読む。

## 進め方

1. 残った案のそれぞれに、C1〜C3 に順に答える。
2. 不合格の案を「不合格のとき」に従って直すか落とす。直したら lint を再実行する。ここまでで1周とする。
3. **2周で止め、残った問題は提示のときに伝える。** 3周目は行わない。周回を重ねるほど無難な方向に収束しやすいためである。
4. 各切り口で1案ずつ残し、`SKILL.md` の手順6の書式で提示する。

## チェック項目

### C1 差し替えテスト

- 問い：案の中の商品名やサービス名を、同じ業種の別の会社に置き換えても成り立つか。商品名が入っていない案は、別の会社の広告に載っていても違和感がないか。
- 合格：置き換えると嘘になるか、意味が通らなくなる。
- 不合格のとき：落とす。型そのもの（例：「〜を、〜で。」）は残してよく、空欄の語を手順3の事実に入れ替えて作り直す。

### C2 言葉遊びの確認

- 問い：言葉遊びを使っている案で、二つの意味の両方が成り立っているか。
- 合格：商品の性質と受け手の気持ちのように、二つの意味がどちらも読める。
- 不合格のとき：音だけが似ている語呂合わせは落とす。社名の語呂合わせも同じ扱いとする。

### C3 事実の確認

- 問い：案の根っこにある事実が、手順3で書き出した3つのどれかに当たるか。
- 合格：狙いの行に書く事実を、3つの中から指させる。
- 不合格のとき：根っこを3つの事実のどれかに付け替えて作り直す。付け替えられない案は落とす。
