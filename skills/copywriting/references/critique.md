# 自己批評

手順5で、lint の違反がゼロになった後に読む。

## 進め方

1. 残った案のそれぞれに、C1〜C3 に順に答える。
2. 不合格の案を「不合格のとき」に従って直すか落とす。直したら lint を再実行する。ここまでで1周とする。
3. **2周で止め、残った問題は提示のときに伝える。** 3周目は行わない。周回を重ねるほど無難な方向に収束しやすいためである。
4. 各切り口で1案ずつ残し、`SKILL.md` の手順6の書式で提示する。

## チェック項目

### C1 差し替えテスト

- 問い：キャッチとサブコピーを組にして、商品名やサービス名を同じ業種の別の会社に置き換えても成り立つか。
- 合格：組で読むと、置き換えたときに嘘になるか、意味が通らなくなる。キャッチだけなら別の店にも言える案（「気持ち」の切り口など）でも、サブコピーがその商品の事実を言っていれば合格とする。
- 不合格のとき：サブコピーに手順3の事実を入れて作り直す。それでも成り立つ案は落とす。型そのもの（例：「〜を、〜で。」）は残してよい。

### C2 言葉遊びの確認

- 問い：言葉遊びや文法の崩しを使っている案で、二つの意味の両方が自然に成り立っているか。初めて読んだ人が、説明なしで一度で分かるか。
- 合格：商品の性質と受け手の気持ちのように、二つの意味がどちらも無理なく読める。
- 不合格のとき：音だけが似ている語呂合わせ、社名の語呂合わせ、狙いの行で説明しないと伝わらない言葉遊びは落とす。その切り口に合う語が素材にないときは、切り口ごと別のものに替える（`angles.md` の0節）。

### C3 事実の確認

- 問い：案の根っこにある事実が、手順3で書き出した3つの事実か、人の言葉のどれかに当たるか。
- 合格：狙いの行に書く事実か言葉を、手順3の書き出しの中から指させる。
- 不合格のとき：根っこを3つの事実か人の言葉のどれかに付け替えて作り直す。付け替えられない案は落とす。
