# 聞き出し

手順2で読む。素材がないと、どんな決まりを足してもコピーは平均的で無難な言葉に戻る。聞き出しは、その商品にしか言えない事実を集めるために行う。

## 1. 1回目の質問

次の4つを1つのメッセージにまとめて出す。選択式の質問ツールが使える環境ではそれを使い、使えない環境では選択肢を番号付きで並べる。依頼の文面ですでに分かっている項目は聞かない。

| 質問 | 形式 | 選択肢 |
|---|---|---|
| 何を書くか | 選択式 | キャッチだけ／キャッチと本文 |
| 何のためのコピーか（商品やサービスの名前と一言の説明） | 自由記述 | なし |
| 一番伝えたいこと | 選択式。自由記述も可 | 機能や性能／使ったときの気持ち／作り手のこだわり／手軽さや価格／世界観 |
| 手元にある素材（具体的な数字、お客さんの言葉、作った理由など） | 自由記述。なくてもよい | なし |

- 4つ目は「なければ空欄でよい」と書き添える。素材がないことを理由に利用者を待たせない。
- web スキルから呼ばれた場合は、web のコンセプトの宣言と同じメッセージで聞く（`SKILL.md` の「web から呼ばれたとき」）。

## 2. 追加の質問

答えから「この商品やサービスにしか言えない事実」が1つも取り出せない場合に限り、追加の質問を1問だけ出す。

- 薄い答えの例：一番伝えたいことに「手軽さや価格」を選んだだけで、素材が空欄。
- 追加の質問の例：「例えば、どんな場面で手軽さを感じてもらいたい？」
- 追加の質問は、選んだ項目を具体的な場面か数字に落とすものにする。新しい項目を聞かない。
- 追加の質問のあとは、答えが薄くても先に進む。推測で補った事実は、提示のときに「（推測）」と書く。
