# LP の本文

手順8で読む。読みやすさより「人が書いた感じ」を優先する。

## 1. 書き方

1. 言い切りを多くする。「〜できます」「〜が可能です」「〜することができます」を減らす。
   - 検出：lint: `dekimasu-ratio`（日本語の文が4文以上あり、これらで終わる文が3割を超えるとき）
2. 同じ文末を3回続けない。
   - 検出：lint: `repeated-ending`
3. 文の長さをそろえない。短い文と長い文を混ぜる。
4. 一般論で始めない（「近年、〜が注目されています」など）。
5. 「と言えるでしょう」「ではないでしょうか」「さまざまな」「多様な」を使わない。
   - 検出：lint: `stock-phrase`（一覧は `anti-patterns.md` の A10）
6. セクションの見出しも、キャッチコピーと同じ基準（`anti-patterns.md`、`critique.md`）で書く。
7. 架空の実績の数字や架空の推薦文を作らない。素材にない数字は「ここに数字」、推薦文は「ここに推薦文」と置く。

## 2. 例

架空の店（駅前の小さな自家焙煎のコーヒー店）を題材に AI が作ったものである。

悪い例（一般論で始まり、「できます」が続き、どの店にも言える）：

> 近年、自宅でコーヒーを楽しむ方が増えています。当店では、さまざまな豆をご用意しています。お好みに合わせて挽き方を選ぶことができます。テイクアウトも可能です。

例：

> 豆を焼くのは、毎朝六時。その日に挽く分だけを、小さな焙煎機で二回に分けて焼く。量は少ない。そのかわり、昼を過ぎても香りが立つ。持ち帰りの袋には、焼いた時刻を手書きで入れている。

## 3. 口調

- 既定は、言い切りの多い「です・ます」とする。上の例のような常体の言い切りは、依頼の雰囲気に合う場合に使う。
- `user-preferences.md` の「口調」に指定があれば、そちらに従う。
- 1つのページの中で、です・ます調と常体を混ぜない。
