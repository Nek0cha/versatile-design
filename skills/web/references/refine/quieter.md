# 落ち着かせる

「落ち着かせて」「うるさい」「派手すぎる」「目が疲れる」のように、画面の刺激が強すぎるという依頼で読む。進め方と守る範囲は `references/refine.md` に従う。

## 目指すこと

- 主役と記憶のフックは残したまま、その周りの刺激を減らす。
- 色、太さ、影、動きのそれぞれに「強いのはここだけ」という場所がある状態にする。

## 見る点

1. アクセントの色が、主要な操作・選択中・肯定的な状態の3つ以外に使われていないか。面積が多すぎないか（`../design-core/references/critique.md` の C6）。
2. 彩度の高い色で塗った大きな面がいくつあるか。状態の色（危険、警告）が通常の表示に使われていないか。
3. 影が、浮いていないものに付いていないか（C8）。
4. 太字、大きな文字、大文字、字間を広げた文字がいくつあるか。見出し以外にも使われていないか。
5. 常に動いているもの、スクロールのたびに動くもの、すべての要素に付いた同じ動きがないか（`../design-core/references/anti-patterns.md` の W2、X12）。静止画では分からないため、動きのコードを読む。
6. グラデーション、発光、ぼかした光の玉などの装飾がないか（X1、X7、X8）。
7. 枠線、区切り線、アイコンの数が多すぎないか。

## 直し方

1. **色**：1で見つけた場所のアクセントをグレーの段階に戻す。主役を示す必要があれば、明暗の反転を使う（`../design-core/references/color.md` の2節）。彩度の高い大きな面は、同じ色相の明度差か、グレーの段階に置き換える。
2. **装飾**：6で見つけたものを消す。禁止リストに当たるため、目的にかかわらず直す。
3. **影と線**：浮いていない要素の影を外す。線は、余白か背景の明度差で区切れる場所から消す。
4. **太さと大きさ**：太字を見出しと主役だけに絞る。大文字と字間を広げた文字は、区分の小さな見出しだけにする。
5. **動き**：動きを主役と記憶のフックだけに絞り、それ以外の動きを消すか短くする。繰り返し続く装飾の動きを止める（読み込み中の表示は除く）。方法は `references/motion-web.md` に従う。
6. **アイコン**：意味が文字と重なっているだけのアイコンを外す。ただし、アイコンとラベルの組（`../design-core/SKILL.md` の6節の6）は崩さない。

主役以外から弱める。主役を弱めるのは、ほかをすべて弱めても刺激が強い場合だけにする。

## やってはいけないこと

- すべてをグレーにして、主役と記憶のフックまで消す。落ち着かせることと、特徴をなくすことは違う。
- 本文の文字色を薄くして静かにする。本文のコントラストは 4.5:1 以上を保つ（C10）。
- 状態の色（危険、警告）を消す。異常な状態は、静かな画面の中で目立つべきものである（X18、X20）。

## 確かめ方

- 直す前と後のスクリーンショットを並べ、アクセントの色が使われている場所をすべて指させるか。後のほうでその数が減っているか。
- 記憶のフックが直した後も最初の画面に見えているか（C2）。
- C6、C8、C10。
