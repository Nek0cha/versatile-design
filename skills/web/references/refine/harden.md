# 壊れにくくする

「壊れにくくして」「エラーのときも見られるように」「長い名前で崩れる」「データがないとき」「読み込みが遅いとき」のように、理想的なデータ以外のときの表示を整える依頼で読む。進め方と守る範囲は `references/refine.md` に従う。

## 目指すこと

- 長い、短い、多い、少ない、遅い、失敗した、のどの場合でも、画面が崩れず、次に何をすればよいかが分かる。

## 見る点

対象の画面について、次の場合を実際に作って見る。データを一時的に差し替えて表示させ、撮る。差し替えに使った仮のデータとコードは、作業の後に元に戻し、生成物に残さない。

| 場合 | 例 | 起きやすい崩れ |
|---|---|---|
| 長い文字 | 名前やタイトルが今の3倍の長さ、改行のない英数字（URL、ID） | はみ出し、横スクロール、ボタンが押し出される |
| 短い文字 | 1文字の名前、空の値 | 行の高さが変わる、ラベルだけが残る |
| 数字 | 0、桁の多い数字、負の数 | 桁がずれる、単位が改行される |
| 件数 | 0件、1件、1000件 | 空の画面、一覧がどこまでも伸びる |
| 遅い | 回線を遅くした状態（開発ツールの通信の制限） | 白紙の時間、届くたびに跳ねる |
| 失敗 | 取得の失敗、保存の失敗、権限がない、オフライン | 何も起きない、「エラー」だけが出る |
| 入力 | 不正な値、送信の連打 | エラーで下の欄が動く、二重に送信される |

## 直し方

- **長い文字**：省略する場所（一覧の名前など）は1行で省略し、全文をツールチップか `title` で読めるようにする。省略しない場所（本文、見出し）は折り返す。改行のない英数字には折り返しの指定（`break-words` など）を付ける。フレックスの子要素には `min-w-0` を付け、はみ出しを防ぐ。
- **数字**：桁を揃える数字は `tabular-nums` にし、単位と数字の間で改行しないようにする。
- **0件**：空状態を用意する。何がないのか、次に何をすればよいかと、その操作を置く（`references/components/states.md`）。
- **多い件数**：一覧の高さに上限を決め、スクロールする領域にする（`references/components/scrollbar.md`）か、ページを分ける。
- **遅い**：すぐ表示できない画面と領域に、中身と同じ形の読み込みの表示を置く（`../design-core/references/anti-patterns.md` の X24、`references/components/loading.md`）。
- **失敗**：何が起きたか、なぜか、次に何をすればよいかを、原因の場所に示す。やり直せる場合は再試行の操作を置く（`references/intuitive-ui.md` の2.4節）。
- **入力**：検証の時期と場所は `references/components/text-input.md` に従い、エラーで周りがずれないようにする（X26）。送信のボタンは処理中に二重に押せないようにする（`references/intuitive-ui.md` の7.4節、`references/components/button.md`）。
- **使えない操作**：隠さずに無効の見た目で表示し、使えない理由を添える（`references/intuitive-ui.md` の2.4節）。

## やってはいけないこと

- 長い文字を、どこでも省略して切る。読む必要のある文章は折り返す。
- 失敗を、トーストだけで知らせて消す。原因の場所に残す。
- 仮のデータやデバッグ用のコードを残す。

## 確かめ方

- 上の表の場合ごとに撮ったスクリーンショットで、はみ出し、重なり、白紙の時間がないか。
- エラーと読み込みの前後を撮って比べ、周りの部品が動かないか（`../design-core/references/critique.md` の C13）。
