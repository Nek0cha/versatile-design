# コピーの書き方

手順4で、キャッチコピー、サブコピー、セクションの見出し、本文を書くときに読む。

- 依頼に書かれた事実（数字、モノの形、使う場面、人の言葉）から書く。事実を足さない。
- 依頼に商品やサービスの情報がほとんどなく、その商品にしか言えないことが書けない場合は、`../design-core/SKILL.md` の5節に従ってダミーの文章を置く。何も言っていないコピーで埋めるより、ダミーのほうがよいためである。
- ボタンやフォームのラベルなどの短い文言は対象外とする。

## 1. 日本語のキャッチとサブコピー

- 短く、静かに言い切る。目安は20文字以内。感嘆符を重ねない。
- 依頼に人の言葉（お客さんの声、作り手の口ぐせ）があれば、それをそのまま、または少しだけ縮めて使う。
- 言葉遊びは、二つの意味が自然に成り立つときだけ使う。音だけのダジャレ、社名の語呂合わせ、説明しないと伝わらないものは使わない。無理に作るくらいなら、素直に言う。
- 受け手に確かめさせるやわらかい問いかけはよい（例：「その差分、意図した変更だけですか？」）。受け手を責める詰問はしない。
- 同じ形の短い語を3つ並べない（「速い。安い。うまい。」）。
- キャッチだけなら誰にでも言える言葉でもよいが、そのときはサブコピーでその商品の事実を一つ言う。キャッチとサブコピーを組にして、商品名を同業の別の会社に置き換えても成り立つなら書き直す。

## 2. 避ける言葉と型

- どの商品にも言える言葉：価値、特別、可能性、すべての人、あなたらしさ、想い、寄り添う、革新、次世代、加速、次のレベル。キャッチや見出しでは、新しい、未来、体験、毎日も避ける。
- 空欄が抽象語で埋まる型：「〜を、もっと〜に。」「〜だけじゃない。〜も。」、抽象語どうしの「AではなくB」。
- 例（AI が作った、どの商品にも言えるコピー）：「毎日を、もっと特別に。」「新しい価値を、すべての人へ。」

## 3. 本文

- 既定は、言い切りの多い「です・ます」とする。1つのページの中で、です・ます調と常体を混ぜない。
- 「〜できます」「〜が可能です」を減らし、言い切りに書き換える。
- 同じ文末を3回続けない。短い文と長い文を混ぜる。
- 一般論で始めない（「近年、〜が注目されています」など）。
- 「と言えるでしょう」「ではないでしょうか」「さまざまな」「多様な」を使わない。
- 架空の実績の数字や推薦文を作らない。必要な場合は「ここに数字」「ここに推薦文」と置く。

## 4. 英語のキャッチ

- 技術系、クリエイター系、海外の利用者も想定するサイトでは、英語のキャッチを使ってよい。
- 3〜5語で、ピリオドで閉じる。
- 業界の語と一般の意味が自然に重なる語を優先する（例：開発者向けなら commit、push、print、ship、branch）。
- 使わない語：Unlock、Elevate、Empower、Seamless、Supercharge、Revolutionize、Transform、Effortless、Next level、Journey。
- 使わない型：「Not just X. Y.」「Where X meets Y」「X, reimagined」。
- 下に日本語のサブコピーを1文添えてよい。英語の直訳にせず、英語が言っていない事実を一つ足す。
